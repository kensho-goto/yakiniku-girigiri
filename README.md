# ジュー（焼肉）

旧名「焼肉ギリギリ」。URL とリポジトリ名（yakiniku-girigiri）は、印刷した試遊会の QR を変えないために そのまま。

焼き加減を見きわめて肉を焼く、スマホ向けのブラウザゲーム（オリジナルのクソゲー）です。
限られた網で、何枚かの肉を同時に焼きます。表と裏の焼け具合と、網から上げたあとの余熱を読みます。焼けた肉は、好みに合う客へ出します。1回は75秒です。

- スマホで遊ぶ：https://kensho-goto.github.io/yakiniku-girigiri/ （合言葉「いいんじゃ」。一緒に作るメンバー用の試作版）
- 参考作品の分析：[docs/references.md](docs/references.md)

## 起動のしかた（パソコン）

```sh
npm start          # http://localhost:8130/ を開く（合言葉なし）
npm test           # 焼け方・余熱・採点・状態管理のテスト
node tools/bot.js  # 自動の遊び手で、作戦ごとの点の出方をくらべる
```

ビルドはありません。`index.html` と `src/` だけで動きます。

## 試遊会（人に遊んでもらう）

```sh
npm run playtest   # この Mac でゲームを動かし、期間限定のURLとQRの画面を Chrome で開く
```

- QR の画面（http://127.0.0.1:8140/qr）を見せて、スマホのカメラで読んでもらいます。同じ Wi-Fi でなくても遊べます。合言葉「いいんじゃ」を聞きます（URL が変わるたびに1回）。
- **変わらない入口**：https://kensho-goto.github.io/yakiniku-girigiri/play/ 。開くと、そのときの試遊会へ自動で飛びます。QR の画面も、この入口の QR を出します（「この QR はずっと同じ」と出ます）。一度印刷すれば、サーバーを動かし直しても使えます。
  - しくみ：URL を作るたびに、試遊サーバーが GitHub の `playtest-url` ブランチの `url.json` に今の URL を書きます。止めると「いまは試遊会をしていません」に変わります。
  - 書くには、この Mac の gh に kensho-goto でログインしていること。書かないときは `--no-publish`（そのときは QR が毎回変わります）。
- 遊ぶ人は、名前（ニックネーム）を入れてから始めます（入れないと始まりません）。
- 感想（またやりたい・まあまあ・わかりにくい・つまらない と、ひとこと）は、1回目のあとと、3回以上遊んだあとにもう1回だけ聞きます。毎回は聞きません。
- 1台のスマホを順番に回すときは、タイトルか結果画面の「次の人に渡す」を押します。名前・自己ベスト・説明済みが消えて、はじめからになります。
- 集計は http://127.0.0.1:8140/playtest で見ます（この Mac からだけ見られます）。出るもの：
  - 遊んだ人数、最後まで遊んだ回数、最後まで2回以上遊んだ人の割合、感想
  - 人ごとの点の伸び
  - どこで読みちがえたか（肉ごとに、焼き足りない・焼きすぎ・余熱で焼けすぎ・ナマ・コゲ）
  - 多かった失敗、ランク、機種ごと（iPhone・Android・パソコン）
  - 最後まで遊ばなかった回（途中でやり直した・ほかのアプリへ移ったまま戻らなかった）
- 記録は `playtest-data/log.jsonl` にだけ残ります（Git には入れません）。1人が送れる量と、記録の大きさ（50MB）に上限があります。
- ゲームは、このコマンドを止める（Ctrl+C）か Mac を閉じると遊べなくなります。URL がとぎれたときは、10秒後に自動で作り直します。入口が自動で新しい URL へ飛ぶので、QR はそのままで使えます。
- 動かしているあいだ、Mac はスリープしません。
- 試しに動かすだけのとき：`PLAYTEST_DATA=/tmp/pt node tools/playtest.js --no-tunnel --no-open`（本番の記録を汚しません）

## 遊び方

| したいこと | 操作 |
|---|---|
| 網に置く | 下のトレーの肉を、網へドラッグ（またはトレーをタップ→網の空きをタップ。続けて置ける） |
| 裏返す | 網の肉をタップ |
| 場所を変える（強火⇔弱火） | 網の肉をドラッグ（または長押し→行き先をタップ） |
| 網から上げる | 皿へドラッグ（または長押し→皿をタップ。長押しは丸い印がたまったら持てる） |
| 客に出す | 皿の肉を客へドラッグ（または皿をタップ→客をタップ） |
| 出す予約 | 網の肉・余熱中の肉を、そのまま客へドラッグ。皿へ上がって、余熱が終わったら自動で出ます（皿に「出す予定」）。その客が帰ったら予約は消えます |
| 捨てる | 焦げた肉・冷めた肉に付く赤い ✕ をタップ（または右の「すてる」箱へドラッグ）。焦げた肉があると箱が光ります |
| 一時停止 | 右上の ‖（アプリを離れても止まる）。戻ると 3・2・1 のあとで再開 |
| 音 | 右上のスピーカー。押すたびに「全部」→「音楽なし（効果音だけ）」→「消音」 |

説明（①置く→②裏返す→③皿へ→④顔へ）は、やることの場所に吹き出しと「動く指」で出ます。ステージ1は★1を取るまで毎回、本番は最初の1回だけ。説明が終わった人でも、1枚も出していないのに皿で待たせていると、皿から客の顔へ運ぶ指が出ます。

上のまん中は「のこり時間」（数字と、緑→黄→赤で短くなる帯）。最初の1枚を置くまで時間は進みません。置いたら「スタート！」、のこり10秒で「のこり10秒！」と大きく出ます。

スマホを横にすると「縦にしてね」と出て、止まります。ホーム画面に追加すると、アプリのように全画面で開きます。

## ステージ（1つずつ覚える）

最初から全部を覚えなくてよいように、7つのステージで1つずつ足していきます。

**腕前**：はじめて「焼く」を押すと「腕前は？」が出ます。初心者＝ステージ1から、中級者＝ステージ4から（1〜4が開く）、上級者＝いきなり本番（ステージも全部開く）。あとで「ステージをえらぶ」の下の「腕前をえらびなおす」から変えられます。ステージを選ぶ画面は、初心者（1〜3）・中級者（4〜6）・上級者（7）の見出しでまとめています。2回目からは「焼く」で次のステージから始まります。

| ステージ | 新しく覚えること | 網・肉・客 | 時間 | 目標（★1）・★2・★3 |
|---|---|---|---|---|
| 1 屋台 | 置く→返す→皿→客 | 中火だけ・タンだけ・客1人・好みは「ほどよく」だけ | 45秒 | 2・4・5枚 |
| 2 裏を読む | 肉汁と煙で裏を読む | カルビが増える・客2人 | 45秒 | 2・5・8枚 |
| 3 好みを聞く | うす焼き・ほどよく・こんがり | 好みが3つに | 60秒 | 2・3・5枚 |
| 4 火を使い分ける | 左から 強火・中火・弱火 | 火力が3つに | 60秒 | 2・3・5枚 |
| 5 余熱を読む | 上げたあとも焼ける | ハラミが増える・客3人 | 60秒 | 2・5・7枚 |
| 6 満席 | にぎわい・フィーバー・肉代・ラストオーダー | 審査員なし | 75秒 | 3・6・9枚 |
| 7 審査員 | 特上カルビ | 本番と同じ | 75秒 | 3・7・10枚 |

- 目標は「うまく焼いて○枚 出せ！」。頼まれた肉を「ふつう」以上で出したら1枚（ナマ・コゲ・冷め・ちがう肉は数えない）。目標が★1で、★1を取ると次のステージが開きます。★3は上手な人むけ。上の欄の左に「目標 1/2枚」、出すたびに「+1枚」。ステージでは点は出しません（本番だけ売上とランク）。
- はじめてのステージでは、先に「新しく覚えること」を3行で見せます。遊んでいる最中も、まだ★1を取っていないステージでは、そのことが起きた場所で1回だけ案内を出します（例：煙が出たら「煙＝下が焦げはじめ」）。
- 使わない席は「準備中」、使わない肉はトレーに鍵と「ステージNから」。
- **本番**（自由に焼く）は、ランクで評価する今までのゲームです。「ステージをえらぶ・本番へとばす」から、いつでも行けます（上手な人はとばしてよい）。
- ★の枚数は `src/sim.js` の `STAGES[].stars`。決め方は `node tools/bot.js --stages`（初心者・慣れた・ふつう・うまいの4人の自動の遊び手で、★1は初心者が、★2は慣れた人が、だいたい届く枚数）。ステージの決まりは `STAGES[].rule`（書いていないものは本番と同じ）。
- 試遊会の集計には「ステージごと」（★1を取れた割合・★1までの回数・わかりにくい）が出ます。むずかしすぎるステージがここで分かります。

## 店のレベルと道具

うまく焼けた枚数（ステージでも本番でも）の合計が「店の経験」。5枚で Lv2、12枚で Lv3 …と上がり、1つ上がるごとに道具を1つ強くできます（4つ×3段＝Lv13で全部）。結果画面の「道具を強くする」か、タイトルの「道具」から選びます。

| 道具 | 1段 | 2段 | 3段 |
|---|---|---|---|
| 🔥 炭 | 焼き始め（焼け具合0.5まで）が +20% 速い | +40% | +60% |
| 🥩 網 | 焼けすぎてからの進み −15% | −30% | −45% |
| 🍽 皿 | 余熱の待ちが半分 | 待ち1/4・冷めにくい | 一瞬・もっと冷めにくい（余熱で焼ける量は同じ） |
| 🥢 トング | 返しどきに肉がピョンと跳ねる | 長押しなしで、すぐ持てる | 焦げそうな肉も跳ねて知らせる |

- **道具が効くのはステージだけ。本番は道具なし**（腕だけの勝負。自己ベスト・ランク・試遊会のくらべあいが公平になる）。道具を強くした段の数は、七輪の枠の色（銅4段・銀8段・金12段）にだけ出ます。
- **繁盛**：道具を1段強くするごとに、ステージで客の来る間が 2.5% 縮みます（12段で 0.7 倍）。
- **★の目標**：★1・★2 は決まった枚数（道具で楽に届く＝行き詰まった人の助け）。★3 だけ、道具4段ごとに +1 枚（12段で +3 枚）。★3 は腕の勝負のまま。
- **炭は焼き始めだけ速い**：全部を速くすると、ちょうどいい時間の幅が縮み、ゆっくりの人ほど焼きすぎます（自動の遊び手で、初心者のうまく焼けた枚数が 1.82→0.74 に落ちた）。焼き始めだけにしたら 1.97 で、落ちなくなりました。
- 調べ方：`node tools/bot.js --stages --tools=3`（道具を全部3段にして、★の届きやすさを見る。`--nohanjo` で繁盛なし）。道具を全部3段にすると、慣れた人の★2は 60〜88% → 92〜100%。うまい人の★3は 0〜43% → 0〜72%。
- 数字は `src/sim.js` の `LV_EXP`（レベルに要る経験）・`TOOLS`・`CFG.sumiUntil`・`CFG.hanjoPerStep`・`CFG.star3PerStep`。
- 参考：Cooking Fever（道具を強くすると調理が速くなる・焦げるまでの時間がある。店が育つと客も増える）、Papa's シリーズ（店で道具を選んで買う・返しどきを知らせるアラーム）、Overcooked（強化なし。★は腕だけ）。どちらも検索結果の説明を読んだだけで、遊んではいない。
- 試遊会の「次の人に渡す」で、店のレベルと道具も消えます。

## ルール（何を見て、何を決めるか）

- **表と裏は別々**：網に当たっている下の面がよく焼けます。上の面は少しだけです。上から見えるのは上の面だけです。裏は次の3つで読みます。
  - 肉の厚みの帯の色
  - 上の面に浮く肉汁（下が焼けてきた合図）
  - 煙（下が焦げはじめた合図）
- **火力**：列ごとに 中火・強火・弱火 です。炭の明るさ、炎、札（炎の数と文字）で分かります。カルビは強火で脂が燃えて、さらに速く焼けます。
- **肉の種類**：タン（うすい・早い）、カルビ（脂・強火で燃える）、ハラミ（あつい・遅い・余熱が大きい）。
- **余熱**：皿へ上げたあとも、少しのあいだ焼けます（輪と「余熱中」の表示）。強火から上げた肉ほど、厚い肉ほど、たくさん進みます。余熱のあいだは出せません。
- **冷め**：余熱が終わると、焼け具合は止まって冷めていきます（湯気が減る）。冷めても生には戻りません。ぬるいと評価が1段下がります。冷めると失敗です。網へ戻せば温め直せます。ただし、焼け具合も進みます。
- **皿の表示**：余熱が終わると、両面の実際の状態を短く出します（「ほどよく」「片面ナマ」「コゲ」「炭」「・ぬるい」など）。「出せる」と「おいしい」は別です。
- **客の好み**：吹き出しに、好み（うす焼き・ほどよく・こんがり）、焼き色の見本、肉の種類（または「肉はなんでも」）が出ます。少し焼きすぎた肉は、こんがり派に回すと救えます。焦げ・炭・ナマは、どの客でも救えません。
- **採点**：両面の悪いほうで決めます。平均はとりません。

  | 評価 | 点 |
  |---|---|
  | 神焼き | 100（＋おまけ30） |
  | うまい | 70 |
  | ふつう | 45 |
  | いまいち | 15 |

  頼まれたのとちがう肉は ×0.6、「どの肉でも」の客は ×0.8 です（好みの肉を頼んだ客に合わせるほうが得）。うまい以上が続くとコンボが伸びます（1つで +10%）。ふつうではコンボは切れず、いまいち以下で切れます。
- **にぎわい（欲張り）**：その肉を焼いているあいだ、一緒に網にあった枚数の平均で点が増えます（1枚で +10%）。何枚置くかは自分で決めます。数えるのは、置いてから20秒以内で、まだ焦げていない肉だけです（置きっぱなしでは増えません）。上の欄に「3枚同時 点×1.2」と出ます。
- **肉代**：捨てた肉は1枚15点、時間切れで網や皿に残った肉も1枚15点、売上から引きます（0点より下にはなりません）。結果画面に「肉代 −○」と出ます。
- **同じ注文は並ばない**：待っている客と同じ注文の客は、なるべく来ません。
- **失敗の反応**：ナマ・片面ナマ・表コゲ裏ナマ・コゲ・炭・冷めた・ぬるい・焼きすぎ・焼き足りない・ちがう肉・待たせて帰った。それぞれ、セリフ・顔・演出・音がちがいます。セリフは客6人ごとに言い方が変わります。
- **ランク**：売上で、肉の等級のように決まります。

  | ランク | 売上 | 呼び名 |
  |---|---|---|
  | C | 〜299 | スーパーの見切り品 |
  | B | 300〜 | 町の焼肉屋 |
  | A3 | 700〜 | ちょっといい店 |
  | A4 | 1100〜 | 予約がとれない店 |
  | A5 | 1600〜 | 霜降りの神 |

  A5 で、失敗0・神焼き5枚以上なら、かくしランク「特選A5」になります。焦げ・炭を4枚以上出すと「規格外（炭）」の判子です。遊んでいるあいだも上の欄に今のランクと次までの近さが出て、上がるとポンと知らせます。結果画面には判子と拍手が出ます（ランクが高いほど拍手が多い）。「次まで あと○点」も出ます。
- **フィーバー**：上の細いメーターは、神焼きで2、うまいで1、ふつうで0.5たまります。4たまると10秒間、点数が2倍になります。客も早く来て、網が金色に燃え、音楽も速くなります。ナマ・コゲ・冷め・帰った客が出るとメーターは0に戻り、フィーバーも終わります。
- **審査員**：22秒と48秒ごろに、王冠の審査員が来ます。そのあいだだけ、トレーの「特上カルビ」が光って、2枚まで焼けます（ふだんは鍵）。好みどおりに出すと点数が3倍です。
- **ラストオーダー**：残り15秒で、客がどっと来て、音楽が速くなります。
- **結果画面**：ランクの判子、売上、自己ベスト、もう一回、称号（その回に起きたことで決まる。例：焦げ4枚以上で「炭の錬金術師」）、内訳、ふりかえり（多かった失敗と次のコツ）。

## ファイル

- `src/sim.js`：ゲームの中身。焼け方、余熱、冷め、客、採点、ふりかえり、称号。画面には触りません。node でテストできます。
- `src/draw.js`：絵。肉・網・炭火・皿・客を、すべて `sim.js` の状態から描きます。
- `src/main.js`：画面の流れ、タップとドラッグ、演出。1/60 秒ずつ固定の刻みで進めます。端末の速さで焼け方は変わりません。
- `src/lines.js`：反応のセリフと顔。
- `src/sound.js`：音（WebAudio で作る。ファイルなし）。

- `src/playtest.js`：試遊会の記録と感想（試遊サーバーがいるときだけ動く）。`tools/playtest.js`：試遊サーバー・QR・集計。
- `manifest.json`・`icon-*.png`：ホーム画面に追加したときの名前とアイコン。
- `tests/sim.test.js`：テスト。`tools/bot.js`：自動の遊び手。

## 見た目の決まり（AI っぽさを出さない）

- 文字を四角い箱に入れない。ふちの太い手書きの字を、店の絵の上にじかに置く（Penguin Diner・にゃんこ大戦争の見せ方）。
- 字は2つだけ：ふだんは Yusei Magic、叫ぶ字・数字は Potta One。どちらも `fonts/` に、使う字だけ入れてある（OFL）。文言を変えて新しい漢字を使ったら `python tools/fonts.py` で作り直す（中に手順あり）。
- 説明は店長が話す。絵文字・カッコの補足・％の数字は使わない。
- アイコンは `tools/icon.html` が元。`node tools/icon.js` で `icon-*.png` を作り直す。
